# Annalyn's Infiltration

**Exercise:** [Exercism - Annalyn's Infiltration](https://exercism.org/tracks/go/exercises/annalyns-infiltration)

## Description

This exercise focuses on Boolean logic and logical operators in Go.

The goal is to determine which actions are possible during a rescue mission based on the awake or asleep state of the knight, archer, and prisoner, as well as the presence of Annalyn's pet dog.

## Concepts

- Booleans
- Boolean Expressions
- Logical Operators (`&&`, `||`, `!`)
- Functions
- Function Parameters
- Return Values
- Conditional Logic

## Solution

The solution implements four functions to determine whether the following actions are possible:

- `CanFastAttack()`
- `CanSpy()`
- `CanSignalPrisoner()`
- `CanFreePrisoner()`

Each function evaluates the characters' states using Boolean expressions and logical operators.

## Key Learnings

- Working with Boolean values (`true` and `false`).
- Using logical AND (`&&`), OR (`||`), and NOT (`!`) operators.
- Combining multiple Boolean conditions.
- Implementing decision-making logic with functions.
- Understanding how logical expressions evaluate to Boolean results.

## Language

Go

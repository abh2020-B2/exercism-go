# Weather Forecast

**Exercise:** [Exercism - Weather Forecast](https://exercism.org/tracks/go/exercises/weather-forecast)

## Description

This exercise focuses on writing documentation comments in Go.

The goal is to document a package, exported variables, and an exported function using proper Go documentation conventions.

## Concepts

- Documentation Comments
- Package Comments
- Function Comments
- Variables
- Go Documentation Conventions

## Solution

The solution consists of adding appropriate documentation comments to the `weather` package, its exported variables, and the `Forecast()` function.

## Key Learnings

- Writing documentation comments in Go.
- Understanding GoDoc conventions.
- Documenting exported identifiers.
- Writing clear and meaningful code documentation.

## Language

Go

# پیش‌بینی آب‌وهوا (Weather Forecast)

## توضیحات تمرین

این تمرین بر نوشتن توضیحات مستنداتی (Documentation Comments) در زبان برنامه‌نویسی Go تمرکز دارد.

هدف، مستندسازی یک Package، متغیرهای عمومی (Exported Variables) و یک تابع عمومی با رعایت استانداردهای مستندسازی Go است.

## مفاهیم استفاده‌شده

- **Documentation Comments:** نوشتن توضیحات مستنداتی برای کد.
- **Package Comments:** مستندسازی Package و معرفی کاربرد آن.
- **Function Comments:** نوشتن توضیحات برای توابع.
- **Variables:** آشنایی با مستندسازی متغیرها.
- **Go Documentation Conventions:** رعایت استانداردهای مستندسازی در Go.

## روش حل

برای حل این تمرین، باید توضیحات مناسبی برای موارد زیر بنویسیم:

1. Package با نام `weather`
2. متغیرهای `CurrentCondition` و `CurrentLocation`
3. تابع `Forecast()`

توضیحات باید کاربرد هر بخش را مشخص کنند، نه جزئیات پیاده‌سازی داخلی آن را.

## نکات یادگیری

- آشنایی با استانداردهای GoDoc.
- نحوه مستندسازی Packageها.
- اهمیت مستندسازی شناسه‌های Exported.
- نوشتن توضیحات واضح و استاندارد برای کد.

## زبان برنامه‌نویسی

Go (Golang)

# Hello World

**Exercise:** [Exercism - Hello World](https://exercism.org/tracks/go/exercises/hello-world)

## Description

A simple introductory exercise to get familiar with the Go programming language.

The goal is to write a function that returns the string `"Hello, World!"`.

## Concepts

- Functions
- Strings
- Package declaration
- Basic Go syntax

## Solution

The solution is implemented using a simple Go function that returns the expected greeting.

## How to Run

```bash
go test
```

# سلام دنیا (Hello World)

## توضیحات تمرین

این تمرین یک مسئله مقدماتی برای آشنایی اولیه با زبان برنامه‌نویسی Go است.

هدف تمرین، نوشتن تابعی است که رشته متنی `"Hello, World!"` را برگرداند.

## مفاهیم استفاده‌شده

- **Functions (توابع):** تعریف و استفاده از تابع در زبان Go.
- **Strings (رشته‌ها):** کار با داده‌های متنی.
- **Package Declaration (تعریف پکیج):** آشنایی با ساختار پکیج‌ها در Go.
- **Basic Go Syntax (سینتکس پایه):** آشنایی با ساختار اولیه کدهای Go.

## روش حل

برای حل این تمرین، یک تابع ساده تعریف می‌کنیم که رشته `"Hello, World!"` را به‌عنوان خروجی برمی‌گرداند.

## نحوه اجرای تست‌ها

برای اجرای تست‌های تمرین، دستور زیر را در ترمینال اجرا کنید:

```bash
go test
```

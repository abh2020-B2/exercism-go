# Gopher's Gorgeous Lasagna

**Exercise:** [Exercism - Gopher's Gorgeous Lasagna](https://exercism.org/tracks/go/exercises/lasagna)

## Description

This exercise introduces the fundamental concepts of the Go programming language through a simple lasagna cooking scenario.

The goal is to calculate cooking and preparation times using constants, variables, and functions.

## Concepts

- Variables
- Constants
- Functions
- Function Parameters
- Return Values
- Basic Arithmetic Operations
- Packages

## Solution

The solution implements functions to calculate the expected oven time, remaining oven time, preparation time, and total elapsed cooking time.

## Key Learnings

- Declaring constants and variables in Go.
- Defining and calling functions.
- Working with function parameters and return values.
- Performing basic arithmetic operations.
- Understanding Go package structure.

## Language

Go

# لازانیای خوشمزه گافر (Gopher's Gorgeous Lasagna)

## توضیحات تمرین

این تمرین با استفاده از یک سناریوی ساده آشپزی (پخت لازانیا)، مفاهیم پایه زبان برنامه‌نویسی Go را آموزش می‌دهد.

هدف تمرین، محاسبه زمان آماده‌سازی و پخت لازانیا با استفاده از ثابت‌ها، متغیرها و توابع است.

## مفاهیم استفاده‌شده

- **Variables (متغیرها):** تعریف و استفاده از متغیرها در Go.
- **Constants (ثابت‌ها):** تعریف مقادیر ثابت با استفاده از `const`.
- **Functions (توابع):** تعریف و فراخوانی توابع.
- **Function Parameters (پارامترهای تابع):** دریافت ورودی در توابع.
- **Return Values (مقادیر بازگشتی):** بازگرداندن نتیجه از توابع.
- **Arithmetic Operations (عملیات حسابی):** انجام محاسبات ساده ریاضی.
- **Packages (پکیج‌ها):** آشنایی با ساختار پکیج در Go.

## روش حل

برای حل تمرین، چهار بخش اصلی پیاده‌سازی می‌شود:

1. تعریف ثابت `OvenTime` برای تعیین زمان استاندارد پخت لازانیا (۴۰ دقیقه).
2. پیاده‌سازی تابع `RemainingOvenTime()` برای محاسبه زمان باقی‌مانده پخت.
3. پیاده‌سازی تابع `PreparationTime()` برای محاسبه زمان آماده‌سازی بر اساس تعداد لایه‌ها (۲ دقیقه برای هر لایه).
4. پیاده‌سازی تابع `ElapsedTime()` برای محاسبه مجموع زمان آماده‌سازی و زمان سپری‌شده در فر.

## نکات یادگیری

- نحوه تعریف ثابت‌ها و متغیرها در Go.
- ساختار و نحوه فراخوانی توابع.
- ارسال پارامتر به توابع و دریافت مقادیر بازگشتی.
- استفاده از عملگرهای حسابی.
- آشنایی با ساختار اولیه برنامه‌های Go.

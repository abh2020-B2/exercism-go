# Welcome To Tech Palace!

A Go exercise from [Exercism](https://exercism.org/tracks/go/exercises/welcome-to-tech-palace) focused on working with strings and the standard `strings` package.

## Description

In this exercise, the task is to implement functions that generate and clean up text messages for a store display.

The exercise consists of three parts:

1. **Welcome Message:** Create a welcome message using the customer's name in uppercase.
2. **Add Border:** Add configurable lines of stars before and after a message.
3. **Clean Up Message:** Remove stars and leading or trailing whitespace from an existing message.

## Concepts

- Strings
- String Concatenation
- String Formatting
- `strings.ToUpper()`
- `strings.Repeat()`
- `strings.ReplaceAll()`
- `strings.TrimSpace()`
- Standard Library Packages
- Functions and Return Values

## Functions

| Function | Description |
|---|---|
| `WelcomeMessage()` | Creates a welcome message with an uppercase customer name. |
| `AddBorder()` | Adds configurable star borders around a message. |
| `CleanUpMessage()` | Removes stars and surrounding whitespace from a message. |

## Key Learnings

- Working with strings in Go.
- Using functions from the standard `strings` package.
- Concatenating strings.
- Repeating characters to generate text.
- Removing unwanted characters and whitespace.

# خوش آمدید به تک پالاس!

## توضیحات تمرین

در این تمرین باید توابعی برای تولید و پاک‌سازی پیام‌های متنی یک نمایشگر فروشگاه پیاده‌سازی کنیم.

تمرین شامل سه بخش است:

1. **پیام خوشامدگویی:** ساخت پیام خوشامدگویی با نام مشتری به حروف بزرگ.
2. **اضافه کردن حاشیه:** قرار دادن خطوط ستاره‌ای با تعداد قابل تنظیم در بالا و پایین پیام.
3. **پاک‌سازی پیام:** حذف ستاره‌ها و فاصله‌های اضافی ابتدا و انتهای پیام.
